# Code of conduct

Aether is a technical project with a public review process. Participants are
expected to make that process safe and productive.

## Expected behaviour

- Discuss code and decisions, not people.
- Give specific, actionable review comments and accept correction gracefully.
- Assume good faith while still requiring evidence for security claims.
- Respect privacy: do not publish another person's private information,
  credentials, or vulnerability details.
- Credit contributors and prior work accurately. Reference implementations must
  not be represented as original Aether code.

## Unacceptable behaviour

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private reports, keys, tokens, or personal data.
- Deliberately misleading claims about security, testing, or compatibility.
- Repeatedly ignoring review requirements or the backlog execution rule.

## Enforcement

Maintainers may edit or remove comments, close contributions, or temporarily
or permanently restrict participation. Reports about conduct are handled
privately by the maintainers. Retaliation against a reporter is itself a
violation.

This policy applies in repository discussions, reviews, chat, and project
events.
